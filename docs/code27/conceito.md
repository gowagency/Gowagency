# Code 27 — Conceito de Marca

> Documento-mãe do posicionamento. Toda decisão de design, copy, atendimento e
> aplicação deve poder ser justificada por esta página. Se não puder, ou a
> decisão está errada, ou este documento precisa ser atualizado.

---

## 1. Posicionamento

**Code 27 é uma barbearia industrial — vertente cofre / sala de máquinas — de
acesso restrito.**

A base é industrial: metal, couro, canos, neon quente, piso escuro. Sobre essa
base, uma camada de leitura mais alta: o lugar funciona como um cofre. O
cliente não compra um corte — ele desbloqueia um espaço que poucos acessam. O
27 é a senha. A impressão digital no logo é a credencial. O "access unlocked"
é o cumprimento. Cada elemento da loja reforça que estar ali é um privilégio
concedido, não um serviço comprado.

A regra que une as duas camadas: **toda peça industrial é também uma peça do
cofre.** O cano não é só cano — é cano que vira o número 27. O cadeado não é
só fechadura — é fechadura do locker do membro. A tela diamantada não é só
revestimento — é a textura repetida que assina a marca.

### O que Code 27 **não** é

Saber o que a marca rejeita é mais importante do que saber o que ela é. Code 27
é industrial — mas três vertentes do industrial são proibidas porque diluem o
posicionamento:

- **Não é industrial boteco-gourmet.** Tijolinho aparente vermelho, lâmpadas
  Edison nuas, madeira de demolição clara, placas esmaltadas. Essa é a
  linguagem de hamburgueria artesanal, não de cofre. O industrial Code 27 é
  metálico, escuro e fechado — não rústico, claro e aberto.
- **Não é um speakeasy.** Speakeasy esconde para criar curiosidade lúdica. Code
  27 não se esconde — ele se mostra fechado. A vitrine é deliberadamente
  visível; o que é restrito é o acesso, não a localização.
- **Não é barbearia "macho alfa".** Sem barba estilizada como ícone, sem
  motos, sem whisky-bourbon-charuto-clichê, sem copy de "homem de verdade". O
  público-alvo é confiante o bastante para não precisar provar.

## 2. Pilares narrativos

Quatro pilares. Toda decisão amarra em pelo menos um. Se uma ideia não amarra,
ela não entra.

### 2.1 Código

A ideia de que existe um sistema fechado, com regras próprias, e quem entende o
código pertence.

- **Design:** o número 27 aparece em escala variável (neon grande, gravado em
  espelho, marcado em recibos, numeração dos lockers). O 27 é desenhado como
  se fosse construído em **cano industrial** — o neon é a sombra desse cano.
  Em qualquer aplicação, o desenho do 27 deve carregar essa estrutura de
  encanamento, mesmo quando estilizado em traço simples.
- **Tipografia CODE:** sempre em caixa alta, espaçamento amplo, peso médio —
  leitura de painel de controle, não de placa. Cor: branco quente (levemente
  amarelado / dourado pálido), nunca branco frio puro.
- **Impressão digital:** o "O" do logo é uma impressão digital estilizada. Ela
  é a credencial gráfica da marca — aparece também isolada (sem o nome) em
  selos, verniz localizado, gravações em couro.
- **Experiência:** o cliente recebe um número (não um horário). "Sua janela: 27
  de junho, 19h27." A repetição do 27 é deliberada e nunca explicada.

### 2.2 Acesso

Tudo na loja simula desbloqueio. Nada é meramente entregue.

- **Design:** cadeados nos lockers (funcionais, não decorativos), porta de
  entrada pesada com puxador de cofre, vitrine iluminada com a frase "Access
  unlocked" embaixo das prateleiras de produto.
- **Experiência:** o agendamento é confirmado com a frase "Acesso liberado" e
  um código de 4 dígitos que o cliente apresenta na chegada. Sem app, sem QR
  code visível — o código é dito, não escaneado.

### 2.3 Ritual

Barbearia comum entrega serviço. Code 27 entrega sequência.

- **Design:** o percurso físico é roteirizado — entrada → vitrine →
  recepção/atendimento → locker (guarda dos pertences pessoais) → cadeira →
  lavatório → saída pela mesma vitrine. Nada é atalho.
- **Experiência:** cada etapa tem nome próprio (ver §3). O barbeiro não
  pergunta "como vai querer hoje?" — ele confirma o registro anterior do
  membro. A repetição é parte do ritual; novidade é exceção.

### 2.4 Reserva

Discrição como luxo. Code 27 nunca grita.

- **Design:** sem promoções na vitrine, sem cartazes, sem QR de Google
  Reviews. A iluminação é baixa e direcionada — a loja é escura por princípio,
  não por estilo.
- **Experiência:** sem música ambiente alta, sem TV ligada em canal aberto,
  sem barbeiro puxando assunto sobre futebol. Conversa existe se o membro
  iniciar. Silêncio é resposta válida.

## 3. Léxico da marca

A marca é construída tanto pelo que se diz quanto pelo que se recusa a dizer.
Esta tabela é regra, não sugestão.

| Conceito genérico | Termo Code 27 | Por quê |
|---|---|---|
| Cliente | **Membro** | Acesso é concedido, não comprado |
| Horário marcado | **Janela de acesso** | Reforça o frame de cofre/timing |
| Agendar | **Solicitar acesso** | Sugere aprovação, não transação |
| Confirmação | **Acesso liberado** | Linguagem de sistema, não atendimento |
| Cancelar | **Revogar acesso** | Mesma lógica, sem dramatismo |
| Produtos à venda | **Arsenal** | Coleção curada, não prateleira |
| Recibo / nota | **Registro de acesso** | Documento, não cupom |
| Cartão-fidelidade | **Credencial** | Não é desconto, é identificação |
| Promoção | _(não existe)_ | Quebra o pilar Reserva |
| Combo | **Sequência** | Quando precisar nomear, é sequência |
| Wifi | **Rede 27** / senha `27` | Coerência sem explicação |

### Proibido dizer

- "Estilo." A marca tem **assinatura**, não estilo.
- "Experiência única." Cliché de hotelaria. Code 27 entrega **ritual**.
- "Conceito." Nunca se descreve como conceito — descreve-se como lugar.
- "Para o homem moderno / homem de verdade / homem que se cuida." Toda copy
  com a palavra "homem" é descartada por padrão.
- Emojis em qualquer comunicação oficial.

## 4. Jornada e ritual de atendimento

Sete pontos onde a metáfora vira contato físico. Nenhum é decorativo.

1. **Solicitação** — site ou WhatsApp. Resposta automática em até 1h: "Acesso
   liberado. Janela: [data, hora]. Código: [4 dígitos]."
2. **Chegada** — porta pesada, sem campainha. O membro empurra. Recepção
   pergunta apenas o código — nunca o nome em voz alta.
3. **Locker** — atendente entrega cadeado físico (numerado). O membro guarda
   celular, casaco, mochila. O cadeado fica com o membro durante a sessão.
4. **Cadeira** — barbeiro chama pelo número da cadeira ("Cadeira 02"), não
   pelo nome. Confirma silenciosamente o registro anterior antes de começar.
5. **Lavatório** — etapa obrigatória, mesmo em corte rápido. Faz parte do
   ritual; não é upsell.
6. **Saída** — pagamento na recepção, devolução do cadeado, entrega do
   "registro de acesso" impresso (papel preto fosco, tipografia branca). A
   frase no rodapé do registro: *Access unlocked — [data, hora].*
7. **Pós** — nenhuma mensagem de "como foi sua experiência?". Silêncio até a
   próxima janela ser sugerida (uma semana antes do intervalo padrão do
   membro). Mensagem única: "Sua próxima janela está disponível."

## 5. Sistema visual — princípios

A paleta e os materiais já estão definidos. O que falta é a **regra de uso**.

### Paleta

| Cor | Função | Regra |
|---|---|---|
| Preto profundo | Estrutura, marcenaria, teto, piso | Cor-base. Quando em dúvida, é preto. |
| Marrom envelhecido / bronze patinado | Paredes, texturas, couro vintage | Profundidade. Nunca dominante; sempre em segundo plano. |
| Laranja âmbar quente | Neon, foco pontual, logo, acentos | **Assinatura, nunca decoração.** Se for usado em mais de 3 pontos por ambiente, está errado. |
| Branco quente (amarelado / dourado pálido) | Tipografia CODE, gráficos, impressão digital | Sempre com leve calor. Branco frio puro é proibido — quebra a temperatura geral da loja. |
| Couro preto legítimo | Cadeiras, sofá Chesterfield | Único material "macio" da loja. Insubstituível por sintético. |
| Latão / bronze envelhecido | Puxadores, cadeados, detalhes, conexões de cano | Acabamento metálico padrão. Inox cromado é proibido. |

### Materiais — princípios

- **Cano industrial é estrutura visível.** Aparece no desenho do 27, em
  pendentes, em barras de apoio, em conexões expostas no teto. Sempre em metal
  escurecido com flanges/conexões em latão envelhecido. Cano nunca é
  decorativo solto — sempre conduz algo (luz, fixação, suporte) ou desenha
  algo (o número, uma moldura).
- **Tela metálica diamantada é repetição, não enfeite.** Aparece no balcão dos
  lockers, na moldura dos espelhos, na vitrine de produtos. Sempre como
  estrutura visível, nunca como aplique decorativo colado.
- **Iluminação é direcionada e quente.** Trilho preto com foco no que importa
  (cadeira, vitrine, neon 27). Temperatura sempre quente (2700–3000K). Luz
  ambiente difusa ou luz fria quebram o conceito de cofre.
- **Marcenaria é fosca, sem brilho.** Verniz acetinado é proibido. Preto fosco
  ou madeira escura envelhecida.
- **Piso é contínuo e escuro.** Microcimento grafite ou porcelanato cimento
  queimado. Sem tapete, sem desenho.
- **Vitrine é suspensa.** A prateleira de produtos da fachada é estrutura
  pendurada — não apoiada no chão. Reforça a leitura de cofre suspenso e dá ao
  "Access unlocked" uma base flutuante.

### Quando **não** usar laranja

- Em mais de um ponto da fachada.
- Em qualquer superfície maior que a tipografia do logo.
- Em tecido, papel, embalagem.
- Em copy digital (Instagram, site) como cor de fundo.

O laranja é a senha visual. Senha repetida vira ruído.

## 6. Aplicações

Pontos onde o conceito sai do espaço físico e vira artefato.

### Credencial (cartão-membro)

- Formato: cartão preto fosco, 85×54mm, sem texto frontal além do número de
  membro gravado a laser e a impressão digital do logo em verniz localizado
  preto-sobre-preto.
- Verso: tipografia CODE branca, número de membro, data de admissão. Sem QR,
  sem chip, sem URL.

### Registro de acesso (recibo)

- Papel preto fosco, tipografia branca em monoespaçada.
- Cabeçalho: `CODE 27 — REGISTRO DE ACESSO`
- Conteúdo: número da cadeira, barbeiro, sequência executada, valor.
- Rodapé: `ACCESS UNLOCKED — [data, hora]`. Sempre em inglês, sempre em caixa
  alta. É a única expressão em inglês permitida na loja.

### Instagram

- Grade: três colunas. Coluna central sempre escura/cheia (foto de detalhe ou
  textura). Colunas laterais alternam entre tipografia branca em fundo preto e
  fotografia de pessoa de costas / em silhueta.
- Nunca mostrar rosto de membro. Nunca mostrar before/after. Nunca usar
  hashtag de barbearia.
- Legenda padrão: uma frase, ponto final. Sem emoji. Sem CTA.
- Bio: `CODE 27 — Acesso restrito. [endereço].` Nada além disso.

### Fachada

- Logo iluminado por trás (já feito).
- Frase única na vitrine, gravada em tipografia branca pequena, na altura dos
  olhos: `Access unlocked.` Sem horário de funcionamento, sem telefone, sem
  redes sociais.
- Endereço e contato vivem apenas no Google Maps e no site.

### Wifi

- Rede: `CODE 27`
- Senha: `27`
- Não há cartaz informando. Quem precisa, pergunta. Quem pergunta, recebe.

## 7. Guard-rails

Três armadilhas que diluem o conceito mais rápido que qualquer outra coisa.
Revisar antes de aprovar qualquer peça nova.

1. **Virar industrial boteco-gourmet.** Sintoma: alguém propõe "uma luminária
   pendente Edison nua", "uma parede de tijolinho aparente vermelho", "uma
   placa esmaltada vintage", "madeira de demolição clara". Resposta: não. O
   industrial Code 27 é metálico, escuro e fechado — não rústico, claro e
   aberto. Voltar para o boteco-gourmet é regredir.
2. **Exagerar no laranja.** Sintoma: laranja em uniforme, em copo, em
   guardanapo, em filtro de Instagram. Resposta: o laranja é assinatura. A
   assinatura existe uma vez por documento.
3. **Copy "macho alfa".** Sintoma: qualquer texto que use "homem de verdade",
   "ritual masculino", "para quem manda", "estilo de rei". Resposta:
   reescrever em terceira pessoa neutra ou em linguagem de sistema. O membro
   não precisa que a marca o valide.

## 8. Teste de coerência

Antes de aprovar qualquer decisão nova (peça gráfica, item de menu, fala de
atendimento, post), responder em voz alta:

1. Em qual pilar isso amarra? (§2)
2. O vocabulário está correto? (§3)
3. Quebra algum guard-rail? (§7)

Se as três respostas não saírem em menos de 30 segundos, a decisão ainda não
está pronta.
